# Perpustakaan Digital (Frontend)

**Nama:** Ratti Nayna
**Mata Kuliah:** Web Framework (WEF02)
**Tugas:** Minggu ke-9

Aplikasi Single Page Application (SPA) Perpustakaan Digital menggunakan Vue.js 3 melalui CDN, JavaScript ES Modules, dan Vue Router, tanpa Node.js dan npm.

## Halaman

- Login
- Dashboard
- Data Buku
- Data Anggota
- Data Author

## Cara menjalankan

1. Buka folder project di VS Code.
2. Klik kanan `index.html`, lalu pilih **Open with Live Server**.
3. Pastikan ada koneksi internet (Vue dan Vue Router dimuat dari CDN).

Jangan membuka `index.html` langsung dengan klik dua kali (alamat `file://`), karena ES Modules akan diblokir browser.
